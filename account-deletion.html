Lazy Pizza Account Deletion Request

To request deletion of your Lazy Pizza account and associated data, please send an email to:

vontonnie@gmail.com

Required Information

  • Phone number used for authentication
  • Request for account deletion

Data Deleted

  • Firebase Authentication account
  • Phone number associated with the account
  • User profile information
  • Order history and associated application data

Deletion Timeframe

Account deletion requests are processed within 30 days of verification.
